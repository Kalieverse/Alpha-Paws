# Paws & Letters — Preschool Edition (ages 3–5)

A playful, offline-friendly (after page loads) alphabet sticker game. Biscuit the fluffy puppy guides children through 26 letters with large picture choices and optional spoken prompts. Children earn stickers and place them on a garden board.

## Features
- 26 alphabet questions with pictures and words
- Fluffy animated puppy mascot (CSS artwork)
- Sticker rewards and draggable garden board
- Parent-gated settings (simple math gate, not strong security)
- Sound on/off, easy mode with two choices (default)
- Reset progress with confirmation
- Progress saved locally in the browser (no accounts, analytics, or ads)

## GitHub Pages
1. Create a public repository named `paws-and-letters`.
2. Upload `index.html` to the repository root.
3. In Settings > Pages, deploy from `main` branch, root `/`.
4. Open the Pages URL after deployment.

## Notes
Speech depends on browser speech synthesis support and available device voices. No external assets or libraries are required. The site does not collect children's personal data. This is an early-learning game, not a comprehensive literacy curriculum.

## Animated garden update
Biscuit now blinks, tilts his head, gently bobs, wags his tail, and jumps when a correct answer is chosen. Flowers sway, clouds drift, butterflies flutter, and stickers pop onto the board. All animations use CSS and work on GitHub Pages without additional libraries. A grown-up setting turns animations off; the device's reduced-motion preference is also respected.
